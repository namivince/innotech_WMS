# 📦 WMS - Warehouse Management System Demo

**Powered by Innotech Vietnam**

## 🚀 Giới thiệu

Đây là ứng dụng demo **Warehouse Management System (WMS)** được phát triển bởi [Innotech Vietnam](https://innotech-vn.com/) - công ty phát triển phần mềm hàng đầu Việt Nam.

## ✨ Tính năng chính

### 📊 Dashboard
- Tổng quan tồn kho theo SKU
- Danh sách đơn hàng chờ xử lý
- Đơn hàng đã hoàn thành chờ xuất đi

### 🛠️ Tạo lệnh Batch-Pick
- Chọn SKU cần lấy hàng
- Gợi ý EPC theo nguyên tắc FIFO
- Tạo batch-pick tự động

### 📃 Xem danh sách Pick
- Hiển thị chi tiết EPC cần lấy
- Thông tin vị trí trong kho
- Gửi danh sách đến thiết bị di động

### 🚶‍♂️ Thực hiện lấy hàng
- Quét RFID tự động nhập EPC
- Xác nhận từng sản phẩm đã lấy
- Theo dõi tiến độ real-time

### 🧠 Trạm phân loại hàng hóa
- Sơ đồ kho hàng trực quan (giống ghế xem phim)
- Quét RFID để phân loại sản phẩm
- Đèn chỉ dẫn thùng chứa (nhấp nháy vàng)
- Xác nhận hoàn thành và lưu log

## 📱 Demo Workflow

1. **Dashboard** → Xem tổng quan
2. **Tạo lệnh** → Chọn SKU và tạo batch-pick
3. **Xem danh sách** → Kiểm tra EPC cần lấy
4. **Thực hiện** → Quét RFID và xác nhận lấy hàng
5. **Phân loại** → Đặt hàng vào thùng đúng và hoàn thành
